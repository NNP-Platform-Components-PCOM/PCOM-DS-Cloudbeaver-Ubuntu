# PCOM-DS-Cloudbeaver-Ubuntu

NNP Data Store (DS) component. Pinned upstream image `dbeaver/cloudbeaver:25.2.0` republished under the NNP namespace.

Published to Docker Hub on every push to `main`:

```
docker.io/nubonativesolution/pcom-ds-cloudbeaver-ubuntu:25.2.0-v1
docker.io/nubonativesolution/pcom-ds-cloudbeaver-ubuntu:latest
```

Architecture: `linux/amd64`. CI/CD via the shared [PCOM-CICD](https://github.com/NNP-Platform-Components-PCOM/PCOM-CICD) reusable pipeline.
